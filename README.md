# CareerVault

CareerVault is a full-stack career and job management platform designed to help users organize and manage their career journey in one place.

The application provides features for managing job opportunities, tracking job applications, maintaining professional profiles, managing skills, and storing career-related information.

## Tech Stack

- **Backend:** Java, Spring Boot
- **Frontend:** React.js, JavaScript, HTML, CSS
- **Database:** MySQL
- **ORM:** Hibernate / JPA
- **API:** RESTful APIs
- **Build Tool:** Maven
- **Development Tools:** Git, GitHub, Postman, VS Code

## Key Features

- User registration and profile management
- Job opportunity management
- Job application tracking
- Resume management
- Skills management
- Personal and professional information management
- RESTful API integration
- MySQL database integration
- Responsive web interface

## Project Goal

The goal of CareerVault is to provide a centralized platform where users can manage their professional information and organize their job search process efficiently.

This project demonstrates practical experience in **Java, Spring Boot, REST APIs, React, MySQL, Hibernate/JPA, and full-stack application development**.
